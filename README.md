지원 환경: Windows 10/11 64비트.

## 프로그램

- **StreamDesk:** 영상 재생·구간 녹화·자동 자막·핵심 요약.
- **CaptureDesk:** 9가지 캡처·이미지 편집·영역 녹화·이미지 및 PDF 저장.
- **워터마크클린:** 하단 별 모양 자동 보정·영역 선택 보정·전후 비교·일괄 처리.
- **온전히 PDF:** 페이지 정리·텍스트와 서명·도형·OCR 및 문서 변환.

## 설치 및 파일 확인

위 링크 또는 각 릴리스의 **Assets**에서 이름이 `Setup-...exe`로 끝나는 파일을 받으세요.
GitHub가 자동으로 표시하는 `Source code (zip)`과 `Source code (tar.gz)`는 설치 파일이 아닙니다.
각 릴리스의 `SHA256SUMS.txt`로 설치 파일의 SHA-256 값을 확인할 수 있습니다.

## 버전 관리

프로그램별로 별도 태그를 사용합니다. 이전 버전과 변경 사항은 [Releases](https://github.com/pjhpms007-collab/desklab-releases/releases)에서 확인할 수 있습니다.
이 저장소는 설치 파일 배포용이며 프로그램 소스 코드를 포함하지 않습니다.
